# Original decorative artwork

These three SVG assets were authored procedurally for the Restaurant Dalmacija Design B prototype. They are original vector compositions; no third-party illustration was downloaded, traced or embedded.

- `olive-branch.svg`: original botanical olive sprig, viewBox `0 0 400 600`, sage and olive greens with dark fruit.
- `dalmatian-coast.svg`: original imagined Adriatic town and harbor engraving, viewBox `0 0 1200 500`. Warm sepia `#8a7658`, muted blue `#486576`, restrained terracotta. It depicts no identified city, landmark or actual restaurant location.
- `paper-grain.svg`: original SVG turbulence texture, a seamless 240 × 240 tile with very low opacity.

All artwork is intended as decorative CSS backgrounds or images with an empty alt attribute. It contains no visible text, scripts, downloaded assets or external resource references. SVG IDs refer only to local gradients and filters.
