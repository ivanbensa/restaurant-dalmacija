# Local font files

These unmodified WOFF2 webfont subsets are served directly from this website. Production pages require no request to Google Fonts or any other font host.

Families and supported upright weights:

- Playfair Display: variable 400–700, for headings.
- Inter: variable 400–700, for body text and controls.
- Great Vibes: regular 400, for the existing wordmark or restrained decorative text.

Latin and Latin Extended subsets support German, Croatian and English, including ČĆĐŠŽ čćđšž, ÄÖÜ äöü and ß. `css/fonts.css` retains the official unicode ranges so the browser downloads only the subsets it needs. All faces use `font-display: swap`. No italic font files are bundled.
